Guia de Faturamento: Consórcios de Saúde (MT)

Um resumo dos processos de credenciamento e faturamento para coordenadores do Faturamento SUS.

Resumo Geral do Processo

Com base nos documentos oficiais, o fluxo para prestadores de serviço (empresas médicas credenciadas) segue este padrão:

  1. Credenciamento: A empresa (Pessoa Jurídica) participa de um Edital de Credenciamento do Consórcio.
  2. Sistema de Gestão: Os atendimentos são gerenciados e autorizados por um sistema web específico (como o SICS ou Pentágono).
  3. Execução: A empresa credenciada realiza o procedimento no paciente, que porta uma "Guia de Atendimento" autorizada.
  4. Faturamento (Quem Fatura): A própria empresa credenciada emite o faturamento (Nota Fiscal/Fatura) contra o Consórcio.
  5. Validação: A empresa confirma a realização do serviço no sistema web (ex: SICS) e encaminha os documentos físicos (guias, NF, certidões) ao Consórcio para conferência.
  6. Pagamento: O Consórcio paga diretamente à empresa credenciada.

Ponto Importante:

Este processo não utiliza o CISA (SISAIH01) que você usa no hospital. O faturamento é feito pela empresa credenciada contra o Consórcio, e não pelo hospital contra o DataSUS.

1. Consórcio Intermunicipal de Saúde do Vale do Teles Pires

  • Responsável pelo Faturamento: A empresa credenciada ("Unidade Executora").
  • Sistema Utilizado: Sistema Web (SICS).
  • Processo:
    1. Agendamento via Centrais de Regulação no SICS (emite "Guia de Atendimento").
    2. Empresa realiza o procedimento.
    3. Empresa confirma a guia dentro do Sistema Web (SICS).
    4. Entre o 1º e 5º dia útil do mês seguinte, empresa encaminha guias originais e NF ao Consórcio.

Documento Chave:

PORTARIA N.º 33/2024 (Processo de Faturamento)

2. Consórcio Intermunicipal de Saúde do Vale do Rio Cuiabá (CISVARC)

  • Responsável pelo Faturamento: A empresa credenciada ("Contratada").
  • Sistema Utilizado: Sistema Pentágono (conforme link "Acesso ao Sistema" no site oficial).
  • Processo:
    1. Empresas habilitadas via Editais de Credenciamento.
    2. Gerenciamento dos serviços pelo Sistema Pentágono.
    3. Empresa apresenta Nota Fiscal/Fatura e Certidões Negativas para pagamento.

Documentos Chave:

Página de Editais de Credenciamento

3. Consórcio Intermunicipal de Saúde da Região do Médio Norte (CISMNORTE)

  • Responsável pelo Faturamento: A pessoa jurídica (empresa) credenciada.
  • Sistema Utilizado: Sistema Web (mencionado nos editais para o credenciamento).
  • Processo:
    1. Empresas solicitam credenciamento via "Sistema Web" no site.
    2. Prestação do serviço conforme demanda gerenciada pelo Consórcio.
    3. Empresa apresenta documentação fiscal para pagamento, conforme rege o edital.
